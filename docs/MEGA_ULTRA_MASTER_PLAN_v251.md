# Mega Ultra Master Plan v251 — Recovery Master

## Objective

Recover the strongest known public build without overwriting the user's mixed
recovery tree, then raise its visual cohesion and runtime resilience while
preserving the approved portal, VEIL field, electricity, rebound particles,
fluid pre-portal aperture, narrative flow, audio, and landscape-mobile contract.

## Recovery decision

- The clean public v250 worktree is the canonical base.
- The recovered tree remains untouched because it mixes older runtime files with
  newer local experiments and unrelated uncommitted work.
- Features are admitted only when they improve the canonical base and receive a
  static regression contract.
- The original portal vortex remains authoritative. The independent spectral
  fluid sequence before it remains a separate transition phase.

## Visual direction

1. Preserve the v250 spectral aperture instead of restoring the flat cyan ring.
2. Preserve the reference VEIL motion beneath the portal, including its fluid
   reaction, static electricity and rebounding particles.
3. Reconnect the crossing's high-DPI speedline canvas and four-point HUD to the
   production video, with restrained violet/cyan/iridescent grading.
4. Use harmonic camera pressure, coherent parallax and optical depth instead of
   random frame jitter or heavy opaque overlays.
5. Keep reduced-motion and mandatory mobile-landscape presentation intact.

## Performance architecture

- Ultra hardware keeps the full 160,000 particles and 35,000 streaks.
- Balanced and economy tiers reduce density and DPR, not choreography.
- WebGL requests the high-performance GPU and caches attribute locations.
- Canvas streaks reuse trigonometric values and solid spectral strokes, avoiding
  per-particle gradients and repeated DOM queries in the frame loop.
- HUD logs mutate only when their visible line count changes.
- The 62 MB production crossing stays `preload=metadata` at startup and warms
  only after the archive-to-map fold crosses 52%.
- Hidden documents stop scheduling warp frames; context loss falls back cleanly.

## Production and regression gates

- Production readiness: repository size, GitHub blob limits, secrets and runtime
  machine paths.
- Optical governance: the recovery layer is declared after cinematic cohesion
  in the frozen stylesheet-order contract, so its overrides remain intentional.
- VEIL/portal fusion, AAA entry, v250 cinematic cohesion and v251 recovery checks.
- JavaScript syntax checks for every changed module.
- Browser verification at desktop and landscape-mobile viewports when a local
  server is available.
- Explicit Git scope review before commit; no recovery-tree files are staged.

## Definition of done

The experience opens from a clean clone, preserves every approved phase, has no
console-breaking syntax error, degrades safely across hardware, passes all five
contracts, and is committed and pushed without secrets or absolute local paths.
