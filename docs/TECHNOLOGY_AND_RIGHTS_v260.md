# Technology And Rights v260

## Runtime technology

- standards-based HTML, CSS and JavaScript modules;
- Three.js runtime modules and GLTF loading;
- Canvas 2D, WebGL/WebGL2, Web Audio and browser media APIs;
- local Node.js static server and validation tools;
- Puppeteer Core for automated Chromium evidence.

## Privacy posture

The published runtime requires no account, analytics SDK, advertising tracker,
telemetry endpoint, cookie or remote database. v259 diagnostics are bounded in
memory and exported only by an explicit local action.
