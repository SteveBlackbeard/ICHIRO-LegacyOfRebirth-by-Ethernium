# Mega Omega Master Plan v255-v260

## Mission

Move ICHIRO from a strong authored prototype to a reproducible production
experience without flattening its identity. Every wave must improve one quality
axis, preserve the approved journey, produce machine-readable evidence, and
remain independently reversible.

## Frozen baseline

The v254 runtime is the comparison point:

- portal, sword, character, map, cursor and approved media stay visually frozen
- activation, authentication, archive fold and crossing timing stay frozen
- audio gesture, cue timing and Web Audio strategy stay frozen
- runtime ownership, phase vocabulary and hidden-tab suspension stay mandatory

## v255 - Optical cohesion

### Objective

Replace subjective CSS accumulation with one measurable optical grammar.

### Delivery

- semantic optical tokens for surfaces, edges, light, danger and focus
- a declared stylesheet order
- complexity ceilings for `!important`, keyframes, filters and shadows
- a CI report that rejects unreviewed visual-debt growth
- named primary silhouettes that effects may support but never veil

### Exit gate

No visual regression and no increase above the recorded v254 CSS complexity
baseline. Future visual work must reuse semantic tokens or explicitly revise the
grammar.

## v256 - Deterministic dossiers

### Objective

Guarantee that all eleven evidence protocols are solvable, persistent and tied
to narrative evidence.

### Delivery

- pure validators and declared answers for protocol logic
- reachability validation for the dossier unlock graph
- correction of witness and consensus validators
- automated protocol contract report
- browser proof for representative binary and evidentiary protocols

### Exit gate

Every dossier has one builder, one deterministic solution, one reachable unlock
path and no soft lock.

## v257 - Accessible interaction

### Objective

Make the authored journey operable with keyboard and assistive technology while
preserving its panoramic presentation.

### Delivery

- shared modal focus ownership and restoration
- focus trapping and Escape handling
- complete tab semantics and arrow-key navigation for lore
- accessible scroll/gesture instruction
- automated semantic and browser keyboard proof

### Exit gate

No keyboard trap, no focus loss on modal close, no hidden focus target and no
interactive control without an accessible name.

## v258 - Secure delivery (complete)

### Objective

Ship the exact approved runtime safely and cache it predictably.

### Delivery

- CSP and security-header contract
- strict MIME and byte-range verification
- content-hashed production derivatives
- dependency and license audit
- reproducible deployment and rollback manifest

## v259 - Field observability (complete)

### Objective

Diagnose failures without collecting personal data.

### Delivery

- local-first health envelope for phase, quality, context loss and asset failure
- long-session and repeated-navigation soak tests
- cold/warm load measurements
- 60/120 Hz and integrated/discrete GPU matrix
- exportable diagnostic report, disabled from network transmission by default

## v260 - Gold (release candidate prepared)

### Objective

Freeze, release and present the strongest coherent version.

### Delivery

- two-week visual freeze
- P0/P1-only change policy
- final cross-browser, accessibility and performance matrix
- checksums, release tag, changelog and rollback agreement
- award judge path and full authored path
- case study, credits, rights and technology disclosure

## Promotion rule

One wave may contain several commits, but one commit may not mix unrelated
visual, interaction, asset and delivery changes. A wave is complete only after
the canonical gate, browser proof, documentation and rollback record all agree.
